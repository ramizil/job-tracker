חלק ב׳ · הסקריפט הקצר (לשיחה)

1מי אני – בפתיחה אחת

נעים מאוד, אני רמי. אני Senior Automation Engineer עם מעל עשור באמדוקס – רוב הזמן האחרון בצוות ה־Core, שבונים תשתית אוטומציה לתרחישי הבסיס של מערכות Billing, CRM ו־OSS/BSS ללקוחות גדולים כמו AT&T ו־T-Mobile.

2המיומנויות והתפקידים – מה באמת עשיתי

הדרך שלי הייתה מגוונת: התחלתי בבדיקות ידניות (System Test, UAT, Smoke), עברתי לאוטומציית Frontend עם Selenium, ואז ל־Core עם אוטומציית Backend ו־REST API ב־Java – Spring Boot, TestNG, Maven – כולל ולידציות מול Oracle ו־Postgres, ושילוב ב־CI/CD על Kubernetes / OpenShift עם Jenkins ו־ArgoCD.

בשנה האחרונה נגעתי גם בבדיקות עומסים עם LoadRunner וניטור ב־Dynatrace ו־Grafana, ובמקביל הרחבתי בצד Python ו־Playwright – כולל framework ציבורי ב־GitHub.

3הערך שאני מביא ומה אני מחפש

מעבר ליום-יום, אני אוהב לזהות עבודה סיזיפית ולבנות כלים שחוסכים זמן לצוות – למשל כלי ל־Jenkins שמחליף שדרוג גרסאות ידני של יום שלם, וכלי שממיר דוחות HTML לסקריפטים של LoadRunner בעזרת GenAI במקום יומיים ידניים.

אני מחפש עכשיו בית מקצועי לטווח ארוך – תפקיד אוטומציה / SDET שבו אפשר להוביל תשתיות, להביא Java ו־Python, ולשלב גם AI בכלים חדשים.
